Installing on a Mac

If macOS says the app is “damaged”

When you open the Mac app for the first time, macOS may say “Pocket Notes.app is damaged and can’t be opened. You should move it to the Trash.” The app is not damaged. It says this because the app is unsigned: signing a Mac app needs an Apple Developer ID certificate, which requires the Apple Developer Program at $99 a year. Pocket Notes is free, so there’s no budget for that yet — and the “Open Anyway” button doesn’t appear for this kind of block.

To open it, do this once:

  1. Open System Settings → Privacy & Security → Full Disk Access. Click + and add Terminal (in Applications → Utilities), and make sure its switch is on.
  2. Open Terminal and run this command:
xattr -cr /Applications/Pocket\ Notes.app
  1. Open Pocket Notes from Applications. It will open normally from then on.

You only need to do this once. Windows and the iPhone/iPad webapp don’t need this step.
